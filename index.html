    使えるモデル

    目安はクレジット

    現在使えるモデルはありません

    つなぎ方

    ChatGPT・Codex・Claude Code で、会話しながら動画・画像・音声・音楽の生成を頼めます。

    使うアプリの手順を開き、A.I.KEN の Google アカウントでログインしてください。

    接続のログインは最長およそ 7 日で切れます。切れたら、そのアプリでログインし直します。

    つなぐ住所（MCP の URL） 
    https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    長い住所やコマンドは、画面では折り返して見えます。［コピー］を使うと、1 行のままコピーできます。

    許可する前に

    ログインと許可は、ご自身で操作してください。「許可する」を押すのは、自分で接続の操作を始め、その流れで開いた画面だけにしてください。人から送られたリンクで開いた画面では許可しないでください。

    許可したあとの画面の URL は、エラーの画面も含めて人に送らないでください。

    画面の名前は変わることがあります。

    ChatGPT

    初めてつなぐ

    会社のワークスペースでは、追加や利用に管理者の許可が必要なことがあります。

    1. ChatGPT の Web 版で 「Plugins」を開きます（別のタブで開きます）。
    2. 「＋」を押します。
    3. 「Add custom MCP server」を選びます。
    4. 「Name」に、次の名前を入れます。
      Name 
      A.I.KEN Studio

    5. 「Connection」の「Server URL」に、次の住所を入れます。
      Server URL 
      https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    6. 「Authentication」で「OAuth」を選びます。
    7. 警告の内容を読んでから、「I understand and want to continue」を選びます。
    8. 「Create as a plugin」を押します。
    9. 表示されたツールの一覧を確かめます。
    10. 「Install」を押します。

    途中で Google のログイン画面や A.I.KEN Studio の許可画面が開いたときは、次の順に進めてください。

    1. A.I.KEN の Google アカウントを選びます。
    2. 自分で始めた接続の流れであることを確かめ、「許可する」を押します。
    3. ChatGPT に戻ります。

    つながったか確かめる

    1. 新しい会話の入力欄で @ を入力します。
    2. 「A.I.KEN Studio」を選びます。
    3. 次の文を、その会話に送ります。
      アプリの会話に送る文 
      A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    残りクレジットや利用枠の情報が返れば、接続できています。

    7 日ほどたって切れたら

    1. 「Plugins」を開きます。
    2. 「A.I.KEN Studio」の接続をやり直します。
    3. ログイン画面が開いたら、A.I.KEN の Google アカウントでログインします。
    4. 自分で始めた接続の許可画面で、「許可する」を押します。

    接続をやり直す項目が見つからないときは、管理者に確認してください。

    Codex

    初めてつなぐ

    コマンドは、Codex CLI を使うパソコンのターミナルで実行します。

    1. 次のコマンドで、接続先を登録します。
      ターミナルに入れるコマンド 
      codex mcp add aiken-media-relay --url https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    2. 次のコマンドで、ログインを始めます。
      ターミナルに入れるコマンド 
      codex mcp login aiken-media-relay

    3. 開いたブラウザで、A.I.KEN の Google アカウントを選びます。
    4. 自分で始めた接続の許可画面で、「許可する」を押します。
    5. Codex に戻ります。

    つながったか確かめる

    Codex の会話に、次の文を送ります。

    アプリの会話に送る文 
    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    残りクレジットや利用枠の情報が返れば、接続できています。

    7 日ほどたって切れたら

    接続先の登録をやり直す必要はありません。

    1. ターミナルで、次のコマンドを実行します。
      ターミナルに入れるコマンド 
      codex mcp login aiken-media-relay

    2. 開いたブラウザで、A.I.KEN の Google アカウントを選びます。
    3. 自分で始めた接続の許可画面で、「許可する」を押します。
    4. Codex に戻ります。
    Claude Code

    初めてつなぐ

    登録のコマンドは、Claude Code を使うパソコンのターミナルで実行します。

    1. 次のコマンドで、Claude Code の版を確かめます。
      ターミナルに入れるコマンド 
      claude --version

      2.1.231 以上なら、次へ進みます。古い場合は、管理者に更新を確認してください。

    2. 次のコマンドで、接続先を登録します。
      ターミナルに入れるコマンド 
      claude mcp add --transport http --scope user aiken-media-relay https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

      --scope user を付けると、どのフォルダで Claude Code を開いても、この接続先を使えます。

    3. Claude Code を開きます。
    4. Claude Code の会話に、次を入力します。
      Claude Code に入れるコマンド 
      /mcp

    5. 一覧から「aiken-media-relay」を選びます。
    6. 表示された案内に沿って、ログインを始めます。
    7. 開いたブラウザで、A.I.KEN の Google アカウントを選びます。
    8. 自分で始めた接続の許可画面で、「許可する」を押します。
    9. Claude Code に戻ります。

    つながったか確かめる

    Claude Code の会話に、次の文を送ります。

    アプリの会話に送る文 
    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    残りクレジットや利用枠の情報が返れば、接続できています。

    7 日ほどたって切れたら

    接続先の登録をやり直す必要はありません。

    1. Claude Code の会話に /mcp を入力します。
    2. 「aiken-media-relay」を選びます。
    3. 「Re-authenticate」を選びます。
    4. 開いたブラウザで、A.I.KEN の Google アカウントを選びます。
    5. 自分で始めた接続の許可画面で、「許可する」を押します。
    6. Claude Code に戻ります。
    うまくいかないとき

    ブラウザが開かない

    接続を始めたアプリの画面を確認してください。Claude Code にログイン用の URL が表示されている場合は、その URL を自分のブラウザで開けます。自分で接続を始めた画面に表示された URL だけを使ってください。

    Codex・ChatGPT で先に進めない場合は、使っているアプリの名前と、URL を除いたエラー文を管理者に伝えてください。

    違う Google アカウントが出る

    許可する前なら、A.I.KEN Studio の画面で「別のアカウントでログイン」を選んでください。A.I.KEN の Google アカウントで入り直します。

    すでに違うアカウントで接続を許可した場合は、そのまま生成を始めず、管理者にアカウントの切り替え方を確認してください。

    別のフォルダで接続先が見えない（Claude Code）

    初めの登録に --scope user が無いと、登録したフォルダでしか見えないことがあります。

    1. 「Claude Code」の手順 2 にある、--scope user 付きの登録コマンドをターミナルで実行します。
    2. 使いたいフォルダで Claude Code を開きます。
    3. /mcp で「aiken-media-relay」があるか確かめます。

    同じ名前の登録があるというエラーが出た場合は、管理者に確認してください。

    ワークスペースで追加できない（ChatGPT）

    管理者に、カスタム MCP サーバーをプラグインとして追加・利用できるか確認してください。

    コマンドで登録できない（Codex：設定ファイルを使う場合）

    管理者と確認しながら、~/.codex/config.toml に次の接続先の項目を追加します。すでに同じ項目がある場合は重ねて追加せず、ほかの設定は残してください。

    設定ファイルに加える例 
    [mcp_servers.aiken-media-relay]
url = "https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp"

    追加後は「Codex」の手順 2 のログインを行います。

    残りクレジットの確認でもエラーになる

    使ったアプリの名前と、URL を除いたエラー文を管理者に伝えてください。ログインや許可のあとに表示された URL 全体は送らないでください。
