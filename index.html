    つなぎ方

    ChatGPT・Codex・Claude Code から使うときの手順です。ログインは、許可された会社の Google アカウント（@a-i-ken.jp / @a-i-ken.com / @orenda.co.jp / @net-fun.co.jp）で行います。

    つなぐ先（MCP の URL） 
    https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    長い URL やコマンドは、画面では折り返して見えます。右上のコピーのボタンを使うと、1 行のままコピーできます。

    自分で始めた接続のときだけ、許可してください。

    ChatGPT アプリ（Codex アプリも同じ）

    ChatGPT のアプリ・Web 版と、アプリの中の Codex は、この手順でつなぎます。

    初めてつなぐ

    1. ChatGPT のアプリ、または Web 版の 「プラグイン」を開きます（別のタブで開きます）。
    2. 「＋」を押し、「カスタム MCP」を選びます。
    3. 名前を入れる欄があれば、次の名前を入れます。 
      aiken_studio

    4. 「タイプ」を「ストリーミング可能な HTTP」に切り替えます（切り替えないと、URL を入れる欄が出ません）。
    5. 「URL」に、次の URL を入れます。 
      https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    6. 「保存」を押します。
    7. 「認証する」を押します。
    8. Google のログイン画面で、研修で案内された Google アカウントを選びます。
    9. 「許可する」を押します。

    つながったか確かめる

    新しい会話で @ を入れ、「aiken_studio」を選んで、次の文を送ります。残りクレジットが返れば成功です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    Codex CLI（ターミナル）

    初めてつなぐ

    1. ターミナルで、接続先を登録します。 
      codex mcp add aiken_studio --url https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    2. ログインを始めます。 
      codex mcp login aiken_studio

    3. Google のログイン画面で、研修で案内された Google アカウントを選びます。
    4. 「許可する」を押します。

    つながったか確かめる

    Codex の会話に次の文を送ります。残りクレジットが返れば成功です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    Claude Code

    初めてつなぐ

    1. ターミナルで、Claude Code の版を確かめます（2.1.231 以上が必要です）。 
      claude --version

    2. ターミナルで、接続先を登録します。 
      claude mcp add --transport http --scope user aiken_studio https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    3. Claude Code で次を入力し、「aiken_studio」を選んでログインを始めます。 
      /mcp

    4. Google のログイン画面で、研修で案内された Google アカウントを選びます。
    5. 「許可する」を押します。

    つながったか確かめる

    Claude Code の会話に次の文を送ります。残りクレジットが返れば成功です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    うまくいかないとき
    • 違うアカウントでログインした：許可する前なら、画面の「別のアカウントでログイン」で、研修で案内された Google アカウントに替えてつなぎ直します。
    • Claude Code で見えない：--scope user 付きで登録し直します（上の Claude Code の手順 2 のコマンド）。
