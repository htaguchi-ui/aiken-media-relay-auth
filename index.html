    つなぎ方

    ログインには、研修で案内された Google アカウントを使います（AIKENメンバーは会社のアカウント）。

    つなぐ先（MCP の URL） 
    https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    途中で出る許可の画面では、自分でつなぎ始めたときだけ「許可する」を押します。覚えのない許可の画面が出たら、「許可しない」を押してください。

    ChatGPT（App）

    ChatGPT のアプリ・Web 版と、アプリの中の Codex は、この手順でつなぎます。

    初めてつなぐ

    1. ChatGPT のアプリ、または Web 版の 「プラグイン」を開きます（別のタブで開きます）。
    2. 「＋」を押し、「カスタム MCP」を選びます。
    3. 名前を入れる欄があれば、次の名前を入れます。 
      aiken_studio

    4. 「タイプ」を「ストリーミング可能な HTTP」に切り替えます（切り替えないと、URL を入れる欄が出ません）。
    5. 「URL」に、次の URL を入れます。 
      https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    6. 「保存」を押します。
    7. 「認証する」を押します。
    8. A.I.KEN Studio の画面に「Google でログイン」が出たら、押します。
    9. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。
    10. 許可の画面で、ログイン中のアカウントを確かめて「許可する」を押します。

    つながったか確かめる

    新しい会話で @ を入れ、「aiken_studio」を選んで、次の文を送ります。残りクレジットが返れば成功です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    Claude（App）

    デスクトップと Web 版（claude.ai）の手順です。画面の名前は英語の表記です（日本語の画面では違う場合があります）。

    初めてつなぐ（個人の Pro・Max）

    1. Claude を開き、Customize > Connectors を開きます。
    2. ＋ Add を押し、Add custom connector を選びます。
    3. Name の欄に、次の名前を入れます。 
      aiken_studio

    4. Remote MCP server URL の欄に、次の URL を入れて、Continue を押します。 
      https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    5. 検出された認証の設定が出たら、Continue を押します。
    6. 次の画面で、Authentication は Sign in now を選びます（No sign in は選びません）。OAuth client は Register automatically を選びます（Use Claude's published identity (Recommended) は選びません）。
    7. Add を押します。
    8. コネクタの一覧で、aiken_studio の Connect を押します。
    9. A.I.KEN Studio の画面に「Google でログイン」が出たら、押します。
    10. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。
    11. 許可の画面で、ログイン中のアカウントを確かめて「許可する」を押します。
    会社の Team・Free プランでは、違いがあります。？
    会社の Team では、コネクタを足せるのは Owner と Primary Owner だけです。Owner は Organization settings > Connectors で Add を押し、Custom > Web を選びます。そのあとは上の手順 3〜7 と同じです（Name は aiken_studio、URL は手順 4 と同じ URL、Authentication は Sign in now、OAuth client は Register automatically を選びます。Use Claude's published identity (Recommended) は選びません）。足したあと、各メンバーが Customize > Connectors で aiken_studio の Connect を押し、自分のアカウントで許可します。Free プランでは、カスタムコネクタは 1 つまでです。

    つながったか確かめる

    新しい会話の入力欄の左下の「＋」 > Connectors で aiken_studio をオンにし、次の文を送ります。ツールの許可の確認が出たら、許可します。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    4. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    Claude Code

    初めてつなぐ
    1. ターミナルで、Claude Code のバージョンを確かめます（2.1.231 以上が必要です。古いときは、講師・スタッフに知らせてください）。 
      claude --version

    2. ターミナルで、A.I.KEN Studio を登録します。 
      claude mcp add --transport http --scope user aiken_studio https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    3. Claude Code で次を入力し、「aiken_studio」を選んでログインを始めます。 
      /mcp

    4. A.I.KEN Studio の画面に「Google でログイン」が出たら、押します。
    5. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。
    6. 許可の画面で、ログイン中のアカウントを確かめて「許可する」を押します。
    つながったか確かめる

    Claude Code の会話に次の文を送ります。残りクレジットが返れば成功です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    うまくいかないとき
    • ログインの途中で止まった・閉じた・5 分を過ぎた：アプリから、つなぎ直します。Codex CLI は Control＋C のあと codex mcp login aiken_studio をもう一度。Claude Code は /mcp で aiken_studio を選び直します。ChatGPT・Claude・Codex のアプリは、接続の画面からもう一度つなぎます。
    • 違うアカウントでログインした：「許可する」を押す前なら、許可の画面のいちばん下の「別のアカウントでログイン」で、研修で案内されたアカウントを選び直します。押したあとなら、講師・スタッフに知らせてください。
    • Claude Code の /mcp に aiken_studio が出ない：その他（CLI）の Claude Code の手順 2 のコマンド（--scope user 付き）で、登録し直します。
    • Claude（App）の会話でツールが出てこない：入力欄の左下の「＋」 > Connectors で、aiken_studio がオンになっているか確かめます。
    • Claude（App）でつながらない：Customize > Connectors で aiken_studio を削除し、Claude（App）の手順 1 から足し直します（会社の Team のメンバーは、Owner に頼みます）。
