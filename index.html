    ChatGPT（App）

    ChatGPT のアプリ・Web 版と、アプリ内の Codex の手順です。

    初めてつなぐ

    1. ChatGPT のアプリ、または Web 版の 「プラグイン」を開きます。
    2. 「＋」を押し、「カスタム MCP」を選びます。
    3. 名前を入れる欄があれば、次の名前を入れます。 
      aiken_studio

    4. 「タイプ」を「ストリーミング可能な HTTP」に切り替えます（切り替えないと、URL を入れる欄が出ません）。
    5. 「URL」に、次の URL を入れます。 
      https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    6. 「保存」を押します。
    7. 「認証する」を押します。
    8. A.I.KEN Studio の画面に「Google でログイン」が出たら、押します。
    9. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。
    10. 許可の画面で、ログイン中のアカウントを確認して［許可する］を押します。

    接続の確認

    新しい会話で @ を入れ、「aiken_studio」を選んで、次の文を送信します。残りクレジットが表示されれば完了です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    Claude（App）

    デスクトップと Web 版（claude.ai）の手順です。画面の名前は英語の表記です。

    初めてつなぐ（個人の Pro・Max）

    1. Claude を開き、Customize > Connectors を開きます。
    2. ＋ Add を押し、Add custom connector を選びます。
    3. Name の欄に、次の名前を入れます。 
      aiken_studio

    4. Remote MCP server URL の欄に、次の URL を入れて、Continue を押します。 
      https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    5. 検出された認証の設定が出たら、Continue を押します。
    6. 次の画面で、Authentication は Sign in now を選びます（No sign in は選びません）。OAuth client は Register automatically を選びます（Use Claude's published identity (Recommended) は選びません）。
    7. Add を押します。
    8. コネクタの一覧で、aiken_studio の Connect を押します。
    9. A.I.KEN Studio の画面に「Google でログイン」が出たら、押します。
    10. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。
    11. 許可の画面で、ログイン中のアカウントを確認して［許可する］を押します。
    Team・Free プランでは違いがあります。？
    Team では、コネクタを追加できるのは Owner と Primary Owner だけです。Owner が Organization settings > Connectors > Add > Custom > Web から、上の手順 3〜7 と同じ設定で追加します。追加後、各メンバーが Customize > Connectors で aiken_studio の Connect を押します。Free プランのカスタムコネクタは 1 つまでです。

    接続の確認

    新しい会話の入力欄の左下の「＋」 > Connectors で aiken_studio をオンにし、次の文を送信します。ツールの許可の確認が出たら、許可します。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    Codex CLI（ターミナル）

    初めてつなぐ
    1. ターミナルで、A.I.KEN Studio を登録します。 
      codex mcp add aiken_studio --url https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    2. ログインを始めます。 
      codex mcp login aiken_studio

    3. A.I.KEN Studio の画面に「Google でログイン」が出たら、押します。
    4. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。
    5. 許可の画面で、ログイン中のアカウントを確認して［許可する］を押します。
    接続の確認

    Codex の会話に次の文を送信します。残りクレジットが表示されれば完了です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    Claude Code

    初めてつなぐ
    1. ターミナルで、Claude Code のバージョンを確認します（2.1.231 以上。古いときは講師・スタッフにお知らせください）。 
      claude --version

    2. ターミナルで、A.I.KEN Studio を登録します。 
      claude mcp add --transport http --scope user aiken_studio https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    3. Claude Code で次を入力し、「aiken_studio」を選んでログインを始めます。 
      /mcp

    4. A.I.KEN Studio の画面に「Google でログイン」が出たら、押します。
    5. Google の画面で、研修で案内された Google アカウントを選びます（出ないこともあります）。
    6. 許可の画面で、ログイン中のアカウントを確認して［許可する］を押します。
    接続の確認

    Claude Code の会話に次の文を送信します。残りクレジットが表示されれば完了です。

    A.I.KEN Studio のツールで、今の残りクレジットを確認してください。生成はしないでください。

    うまくいかないとき
    • ログインの途中で止まった・閉じた・5 分を過ぎた：アプリから再度接続します。Codex CLI は Control＋C のあと codex mcp login aiken_studio を再実行します。Claude Code は /mcp で aiken_studio を再度選びます。アプリは接続の画面から再度接続します。
    • 違うアカウントでログインした：［許可する］の前なら、許可の画面の下の［別のアカウントでログイン］で、案内されたアカウントを選びます。押したあとは講師・スタッフにお知らせください。
    • Claude Code の /mcp に aiken_studio が出ない：Claude Code の手順 2 のコマンドで再登録します。
    • Claude（App）の会話でツールが出てこない：入力欄の左下の「＋」 > Connectors で、aiken_studio がオンか確認します。
    • Claude（App）で接続できない：Customize > Connectors で aiken_studio を削除し、手順 1 から再度追加します（Team のメンバーは Owner に依頼します）。
