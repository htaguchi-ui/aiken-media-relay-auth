    つなぎ方

    ChatGPT・Codex・Claude Code から A.I.KEN Studio につなぐと、会話しながら生成を頼めます。ログインは、それぞれのアプリの接続の操作から、A.I.KEN の Google アカウントで行います。

    つなぐ住所（MCP の URL）
    https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp

    ChatGPT

    上の住所を、ChatGPT のコネクタとして登録して使います。

    ログインから 7 日たつと接続が切れます。そのときはコネクタをつなぎ直します。

    Claude Code
    1. 版が 2.1.231 以上か確かめます（claude --version）。
    2. 登録します：claude mcp add --transport http aiken-media-relay https://tnzwhwitgnzoehbjrmoy.supabase.co/functions/v1/mcp
    3. Claude Code で /mcp → aiken-media-relay → ログイン。ブラウザで A.I.KEN の Google アカウントでログインし、許可の画面で「許可する」を押します（自分で操作した流れで開いたときだけ）。

    ログインから 7 日たつと接続が切れます。そのときは 3 のログインをやり直します。
